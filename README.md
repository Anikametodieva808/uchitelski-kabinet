# Учителски кабинет – Строителна катедра

Готов адаптивен сайт на български език с начална страница, учебна библиотека, търсене, филтър по предмети, вход/регистрация и форма за добавяне на материали.

## За да работи за няколко учители
GitHub Pages е само хостинг и не дава обща база данни или профили. Този проект използва Supabase за профили и споделени записи.

1. Влез в https://supabase.com и създай проект.
2. Отвори SQL Editor → New query.
3. Копирай съдържанието на `supabase-schema.sql` и натисни Run.
4. В Project Settings → API копирай Project URL и anon/public key. Никога не използвай `service_role` ключа в сайта.
5. Отвори `config.js` и попълни:
   `window.APP_CONFIG={SUPABASE_URL:"https://ТВОЯТ-ПРОЕКТ.supabase.co",SUPABASE_ANON_KEY:"ТВОЯТ_ANON_PUBLIC_KEY"};`
6. В GitHub създай хранилище `uchitelski-kabinet` и качи всички файлове от папката.
7. В GitHub отвори Settings → Pages → Deploy from a branch → `main` → `/ (root)` → Save.
8. В Supabase Authentication → URL Configuration добави публикувания GitHub Pages адрес в Site URL и Redirect URLs.
9. Сподели адреса с колегите. Те могат да създадат профили. За училищна употреба настройте контрол на регистрациите преди широко споделяне.

## Ограничения
- В тази версия материалът се описва със заглавие, предмет, вид, описание и незадължителна връзка към файл. Качване на файлове директно в сайта не е включено; използвайте OneDrive/SharePoint връзки или настройте Supabase Storage.
- По подразбиране всички вписани потребители могат да добавят записи, но само авторът може да редактира/изтрива собствените си записи.
- Не публикувайте лични данни на ученици.
- Докато `config.js` не е настроен, сайтът показва демонстрационни материали и профилите не работят.
